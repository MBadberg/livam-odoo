Configuration
=============

Requires :mod:`livam_connector` (configure LiVaM Base URL, Operator-Token and
Order-Webhook-Secret there) and the OCA ``contract`` module.

Set the following on a sale order (tab *LiVaM*) before confirmation:

* **Tenant-Wunschname** or **Eigene Domain** — exactly one of the two.
* **Abrechnungszyklus** — monthly or yearly.
* **Feature-Keys** — optional, comma-separated Lingavena feature keys.

A cron syncs paid invoices to LiVaM every hour.

Usage
=====

Confirm a sale order with a tenant identifier set. The module then:

1. calls ``POST /webhooks/orders`` (HMAC-signed) and stores the license id,
2. creates a recurring ``contract.contract`` (monthly or yearly),
3. on the first paid invoice calls ``POST /licenses/:id/mark-paid`` and on each
   later paid invoice ``POST /licenses/:id/renew`` (via the hourly cron).

The flow is fail-closed: a failed provisioning call rolls back the order
confirmation.
