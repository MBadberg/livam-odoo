Mirror LiVaM licenses, installations, releases and SaaS instances into the
Odoo backend and link each license to a customer (``res.partner``). Write
actions (mark-paid, renew, suspend/activate, feature changes, tenant move,
certificate revocation, release activation) call the LiVaM operator API and
then re-sync the record.

Configuration
=============

Requires :mod:`livam_connector` (configure the LiVaM Base URL and Operator-Token
there). Assign the *LiVaM-Manager* group to the operators who may manage
licenses, installations, releases and SaaS instances.

Usage
=====

Use the *LiVaM* menu:

* *Synchronisieren* mirrors the complete LiVaM operator view (licenses,
  installations, releases and SaaS instances).
* *Lizenzen*, *Installationen*, *Releases* and *SaaS-Instanzen* list the
  mirrored records; each form offers the matching write action.
* *SaaS-Instanz registrieren* creates a new SaaS instance in LiVaM.

Mirroring is read-through: Odoo stores only LiVaM metadata; every write action
calls the LiVaM operator API and then re-syncs the record.
