Configuration
=============

After installation open *Settings → LiVaM* and set:

* **LiVaM Base URL** — base URL of the LiVaM instance (e.g.
  ``https://lus.lingavena.de``).
* **Operator-Token** — the ``LIVAM_OPERATOR_TOKEN`` used for the operator API.
* **Order-Webhook-Secret** — the ``LIVAM_ORDER_WEBHOOK_SECRET`` used to sign
  shop webhooks.

All values are stored in ``ir.config_parameter`` and never logged.

Usage
=====

Build a client from the configured parameters::

    from odoo.addons.livam_connector.models.livam_client import get_livam_client

    client = get_livam_client(env)
    client.create_order({...})                    # signed order webhook
    client.check_tenant_availability(tenant_slug="hans")
    client.operator_request("GET", "/licenses")   # bearer-authenticated
